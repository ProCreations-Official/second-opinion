Super-powered parallel workers

A manager model can start 1–32 fresh native-harness workers with distinct roles. Claude can orchestrate lower-cost Codex Luna workers; Codex can orchestrate Claude Sonnet or Grok workers. The direction, model, effort, and worker count are yours.

Build

Divide implementation

Core code, tests, edge-case hardening, tooling, and integration/docs run concurrently with collision-aware role prompts.

Review

Five independent lenses

Correctness, security, tests, performance, and product integration use read-only consult mode by default.

Balanced

Work plus verification

Mix builders and independent reviewers while the parent orchestrator keeps working, steers tasks, and synthesizes results.

Choose with current benchmark evidence

The built-in Artificial Analysis tool needs no API key or account. It exposes Intelligence, Coding, and Agentic indices, average cost/time per task, and the separate harness-specific Coding Agent Index as attributed JSON for manager models.

One place for every worker

The separate task manager discovers individual tasks and parallel teams started by any connected coding agent. Read live output, steer the next turn, switch model or effort, stop, retry, and archive—without modifying an agent app.

Default

Native app window

Python and Tk keep startup quick and memory small across macOS, Windows, and Linux. No browser, Electron runtime, or local server.

Optional

Terminal manager

Use --manager terminal for a separate interactive CLI window with the same core task controls.

Optional

No window

Use --manager none or --no-window. The agent still runs and normal CLI behavior stays isolated.

Agent Matrix

Second Opinion installs native skills that teach each agent how to decide when another chat is useful, then start the best-fit installed agent in the background for a scoped task.

Codex

Backend and general build

Best first stop for APIs, data flow, tests, repo-wide edits, debugging, and most implementation work. Less specialized for high-polish visual UI.

Claude Code

UI and design polish

Strong first choice for frontend polish, responsive layout, product copy, and visual judgment. Use the latest/highest Claude model available, often Opus-class when available.

OpenCode

Fast provider-flexible checks

Fast and easy for quick exploration across configured models and providers. Quality depends heavily on the selected model, so verify cheaper model results carefully.

Grok Build

Fast exploration

Useful for broad investigation, implementation spikes, and xAI/Grok-specific tasks.

Antigravity

Google orchestration

Useful for Gemini-backed analysis, Google stack work, and async agent workflows.
